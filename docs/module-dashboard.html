# inner inicializarDashboard()

Inicializa la página de dashboard, mostrando una alerta con el nombre del usuario que ha iniciado sesión, y configurando la navegación según el rol del usuario. Si el usuario no es administrador, elimina el botón de usuarios del DOM. Agrega listeners a los botones de navegación, y al botón de logout.
